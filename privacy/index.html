Your data

Privacy

What ASRBMY Write collects — which is very little.

Summary#

ASRBMY Write is a static website. It has no accounts, no comments, no contact form and, by default, no analytics or advertising scripts.

What the site stores in your browser#

One optional feature keeps a small amount of data in your own browser only (using localStorage). It is never sent to a server:

  • your chosen colour theme (light or dark);
  • your reading list, if you use “Save for later”.

You can remove it at any time by clearing the site's data in your browser settings.

Analytics#

This site does not use analytics, advertising or tracking scripts.

Hosting#

The site is served by GitHub Pages. Like any web host, the hosting provider may keep technical logs such as IP addresses and request times. See GitHub's own privacy statement for details about what it collects.

External links#

Articles link to other websites. Those sites have their own policies, and ASRBMY Write is not responsible for them.

Changes#

If anything here changes — for example, if analytics are added — this page will be updated.
