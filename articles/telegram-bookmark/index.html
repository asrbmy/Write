Telegram Bookmark#

Save any link, file, screenshot, page or video to your own Telegram group, sorted into topics. Telegram becomes your bookmark manager, with search, sync across all your devices, and no extra account.

  • Version: 2.0.0
  • Developed by: asrbmy and linkwithiq
  • Websites: asrbmy.github.io · linkwithiq.github.io
  • Source code: github.com/asrbmy/telegram-bookmark

1. How it works#

text
Browser extension  ──►  Telegram Bot API  ──►  Your group (Topics on)
   (popup, menu,                                 ├─ 🎬 Videos
    shortcut)                                    ├─ 🎵 Music
                                                 ├─ 🌐 Websites
                                                 ├─ 📄 Documents
                                                 ├─ 🖼️ Images
                                                 └─ 📌 Read later
  1. You create a Telegram bot and a group with Topics turned on. Each topic is a category.
  2. The extension sends your saves through the bot to the right topic.
  3. Optionally, a small helper program on your own computer downloads videos and music (for example from YouTube) with yt-dlp and uploads them to the same topic.

Everything runs on your own devices. There is no server owned by the developers and no analytics.

2. What is in the download#

File Purpose
telegram-bookmark-chrome.zip Extension for Chrome, Edge, Brave and other Chromium browsers (Manifest V3)
telegram-bookmark-firefox.zip Extension for Firefox (Manifest V2)
telegram-bookmark-helper.zip Optional helper for video and audio downloads (server.py + README)

3. Install the extension#

Chrome, Edge, Brave#

  1. Extract telegram-bookmark-chrome.zip into a folder.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the extracted folder.
  5. Pin the extension from the puzzle-piece menu so the icon is always visible.

Requires Chrome 110 or newer.

Firefox#

  1. Extract telegram-bookmark-firefox.zip into a folder.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and select the file manifest.json (the file, not the folder or the zip).

Firefox removes temporary add-ons when it closes, so repeat these steps next time. Your settings are kept.

To keep it permanently, either:

  • Upload the zip to addons.mozilla.org → Developer Hub → On your own, then install the signed .xpi it gives you, or
  • Use Firefox Developer Edition or Nightly, set xpinstall.signatures.required to false in about:config, and install the zip.

Requires Firefox 109 or newer.

4. Set up Telegram#

You do this once. It takes about five minutes.

Step 1: Create a bot#

  1. In Telegram, open @BotFather (it has a blue verified tick).
  2. Send /newbot.
  3. Choose a name, then a username ending in bot.
  4. Copy the token. It looks like 123456789:AAH-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.

Anyone with the token can control your bot. If it leaks, send /revoke to @BotFather.

Step 2: Create the group#

  1. Create a new Telegram group. Telegram needs at least one other member to create it. You can remove them afterwards.
  2. Open the group, tap its name, tap Edit, and turn on Topics.
  3. Add your bot to the group.
  4. Open Administrators, add the bot, and turn on Manage Topics.
  5. Send any message in the group, for example "hello".

Step 3: Connect the extension#

  1. Open the extension's Settings (the sliders icon in the popup).
  2. Go to Account and paste the Bot token.
  3. Click Find my group. The Group ID is filled in for you. It looks like -1001234567890. If you are in several groups with the bot, you get a list to choose from.
  4. Click Test connection. You should see four green ticks:
    • Bot is valid
    • Group found
    • Topics are enabled
    • Bot is an admin and can manage topics
  5. Go to Topics and click Create missing topics in Telegram. The six default topics appear in your group.

Settings save automatically. You will see a small "Saved" message at the bottom.

Manual Group ID: open https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates in your browser and look for "chat":{"id":-100.... Copy that number including the minus sign.

5. Using the popup#

Click the extension icon on any web page.

Area What it does
Page card Shows the page icon, title and site name
Duplicate banner Appears if you already saved this link (see section 9)
Topic Chips for each category. The best match is selected automatically. Click another to change it
Save as Link, File, Shot, Page, and (if the helper is on) Video and MP3
Note field Optional text or #tags. Press Enter to send. Your note is kept if you change topic
Send to Telegram The main button. It changes to Send again when the link is a duplicate
Save all N tabs Sends every open tab in this window (needs Advanced access)
Group selector Top right. Appears when you have more than one profile
Settings (sliders icon) Opens the settings window
Save / History Switch between saving and your history at the bottom

If the bot is not connected yet, the popup shows a Connect Telegram screen with a button that opens Settings.

6. Save modes in detail#

Mode What is sent Notes
Link A message with the page title, URL and your note Default. Telegram shows its normal link preview
File The actual file (PDF, MP3, MP4, image, ZIP, etc.) uploaded as a document Needs Advanced access. Falls back to a link if the URL is a normal web page or the file is over 50 MB
Shot A screenshot of the visible part of the page PNG. Sent as a photo, or as a document if it is over 9 MB or Telegram rejects it as a photo
Page An HTML copy of the page, as a .html file Scripts are removed, a no-scripts security policy is added, and a base address is set so images and styles load when you open it online. It is not a fully offline archive
Video Video downloaded by the helper (up to 720p MP4) Needs the helper
MP3 Audio downloaded by the helper as MP3 Needs the helper and ffmpeg
Text Your highlighted text plus the source title and link Used from the right-click menu when you select text
Tabs All tabs in the window as a list Needs Advanced access. See below

Automatic file mode. If Advanced access is on and the page address ends in a file type (pdf, docx, xlsx, pptx, zip, mp3, m4a, mp4, jpg, png, webp, epub), the popup selects File for you. Otherwise it starts on Link.

Save all tabs. All tabs go into one message (or a few, if the list is long) to stay within Telegram's rate limits. Link previews are turned off for this list, up to 200 tabs are sent, and the message starts with "📚 N tabs" and your note.

Safe file downloads. The extension fetches files without your login cookies, stops after 120 seconds, refuses to read more than 50 MB, and blocks local and private network addresses (including after redirects).

7. Right-click menu and keyboard shortcut#

Right-click menu#

Right-click a page, link, image, video, audio file or selected text, then choose Save to Telegram:

  • One entry per topic. Sends a link. If you right-clicked selected text (not on a link), it sends the text as a Text save with the source.
  • ⬇️ Download file instead. Available on links, images, video and audio. Uses the automatic topic.
  • 🎞 Download video (helper) and 🎧 Download audio (helper). Only shown when the helper is enabled.

Keyboard shortcut#

Alt + Shift + S saves the current page as a link to its automatically detected topic.

Change it here:

  • Chrome: chrome://extensions/shortcuts
  • Edge: edge://extensions/shortcuts
  • Firefox: Add-ons → gear icon → Manage Extension Shortcuts

Badges#

Saves from the right-click menu and the shortcut show a small badge on the toolbar icon for 2.5 seconds:

Badge Meaning
✓ Sent
⬇ File uploaded
… Helper download started
= Skipped because it is a duplicate
! Error. Open the popup to see details

8. Automatic topic detection and site rules#

The topic is chosen in this order:

  1. Your site rules (Settings → Site rules).
  2. Built-in detection:
Detected Topic
youtube.com, youtu.be, vimeo.com, dailymotion.com, twitch.tv Videos
music.youtube.com, spotify.com, soundcloud.com, gaana.com, jiosaavn.com, music.apple.com Music
.mp4 .mkv .webm .mov Videos
.mp3 .m4a .wav .flac .ogg Music
.pdf .doc(x) .xls(x) .ppt(x) .zip .epub Documents
.jpg .png .gif .webp Images
Everything else Websites
  1. If the detected topic does not exist in your profile, the first topic in your list is used.

Site rules. In Settings → Site rules, type a website and pick a topic. A rule for github.com also covers gist.github.com and other subdomains. Rules apply to the popup, the right-click menu and the shortcut. A rule that points to a topic you deleted is ignored.

9. Duplicate warning#

When you try to save a link that is already in your history, you get a warning instead of a second copy.

  • Applies to Link, File, Page, Video and MP3 saves.
  • Tracking parts are ignored when comparing: #fragments, utm_*, fbclid, gclid, igshid, and si.
  • In the popup, the banner says when and where it was saved, and the button becomes Send again. Pressing it saves a duplicate on purpose.
  • From the right-click menu and the shortcut, a duplicate is skipped and the badge shows =.
  • Turn this off in Settings → Features. Duplicate checking needs history to be on.

10. History#

Open the History tab in the popup.

  • Search by title, link or note.
  • Open a saved link in a new tab.
  • Send again re-sends it as a link to the same topic.
  • Shows the last 60 matches for the current group.

In Settings → History you can Export JSON or Clear history. In Settings → Features you choose how many items to keep: 100, 300 or 1000. Turning history off stops it recording and also disables the duplicate warning.

11. Multiple groups (profiles)#

Use a separate Telegram group for each area of life, for example Personal and Work.

  • Each profile has its own bot token, Group ID, topics and history.
  • Site rules and feature settings are shared by all profiles.
  • Create, rename and delete profiles in Settings → Account.
  • Switch profile with the selector at the top of the popup. The right-click menu follows the active profile.
  • Site rules point to a topic by its internal key, so a rule only applies in profiles that contain that topic.

12. Settings reference#

Account#

Group profile, profile name, bot token (hidden, with a Show button), Group ID, Find my group, Test connection, New profile, Delete profile, and quick setup steps.

Topics#

  • Edit the icon, name and topic ID of each category.
  • Add your own topics. Remove topics you do not want.
  • Create missing topics in Telegram creates a forum topic for each category that has no ID yet. The group must have Topics turned on and the bot needs the Manage Topics right.
  • Renaming a topic here does not rename it in Telegram. Rename it in Telegram too.
  • If a category has no topic ID, saves go to the group's General topic.

Site rules#

Add, view and remove website → topic rules.

Features#

Setting What it does
Advanced access Asks the browser for access to all websites. Needed to download files and to read all tabs for Save all tabs. Off by default
Duplicate warning On or off
Keep history On or off
History size 100, 300 or 1000 items
Keyboard shortcut Information on how to change it

Helper#

Enable the helper, set its address (default http://127.0.0.1:8765) and secret, and press Test helper to check that it runs and that yt-dlp and ffmpeg are installed.

History#

Export or clear your history.

About#

Version, developer credits, links, privacy summary.

13. The download helper (YouTube and more)#

Browsers cannot download YouTube videos from inside an extension. The helper is a small Python program on your computer that does it with yt-dlp, which supports YouTube and over a thousand other sites.

Install#

  1. Install Python 3.9 or newer.
  2. Run python -m pip install -U yt-dlp.
  3. Install ffmpeg. It is needed for MP3 and for joining video and audio.
  4. Extract telegram-bookmark-helper.zip and run python server.py.
  5. It prints a secret. In the extension go to Settings → Helper, turn the helper on, paste the secret and press Test helper.

Use#

  • In the popup, choose Video or MP3 and press Send.
  • Or right-click a page or link → Save to Telegram → Download video (helper) or Download audio (helper).
  • The file appears in the chosen topic when it is ready. The popup only says the download has started.
  • If a download fails, the bot posts a short reason and the link in the same topic.

How it behaves#

  • Video: up to 720p, MP4. Audio: MP3 at best quality. Only the single video, never a whole playlist.
  • Up to 2 downloads run at the same time.
  • Temporary files are deleted after each job.
  • Videos are sent as videos and audio as audio. If Telegram refuses that, the file is sent as a document.

Options#

text
python server.py --port 8765
python server.py --secret MY_OWN_SECRET
python server.py --max-mb 50
python server.py --api-base http://127.0.0.1:8081 --max-mb 1900

The secret can also come from the HELPER_SECRET environment variable. By default it is generated once and stored in ~/.telegram-bookmark-secret.

Files over 50 MB#

The public Telegram Bot API accepts uploads up to 50 MB. For files up to 2 GB, run your own Telegram Bot API server, log your bot out of the cloud API once with /logOut, then start the helper with --api-base and --max-mb 1900 as shown above.

Helper security#

  • Listens only on 127.0.0.1.
  • Requires the secret on every request.
  • Rejects requests from web pages (browser Origin check) and from other host names (protects against DNS rebinding).
  • Accepts only http and https links, validates the token and Group ID format, and limits the request size to 8 KB.
  • Starts yt-dlp with an argument list, never through a shell, and passes the link after -- so it cannot be read as an option.
  • Hides your bot token in any error message.
  • Your bot token is sent only from the extension to the helper on your own computer, and from there to Telegram.

14. Privacy and security#

What is stored#

Everything is in your browser's local extension storage: profiles (token, Group ID, topics), site rules, settings and history. Nothing is synced to any developer server. The token is stored as plain text on your device, as is normal for extensions. Anyone with access to your browser profile could read it.

Network connections#

The extension connects only to:

  • api.telegram.org to send your saves
  • Your own helper at 127.0.0.1 or localhost, if you enable it
  • A web address you choose to download, only when you use File mode with Advanced access on

Permissions#

Permission Why
storage Save your settings and history
contextMenus The right-click menu
activeTab Read the current tab's title and address, take screenshots and copy the page when you click
scripting (Chrome only) Copy the page HTML for the Page mode
api.telegram.org, 127.0.0.1, localhost Talk to Telegram and the helper
All websites (optional) Requested only if you turn on Advanced access. Used for file downloads and Save all tabs

Built-in protections#

  • Only http and https links can be saved. javascript:, file: and browser pages are blocked.
  • Telegram messages are sent as plain text, so page titles cannot inject formatting or links.
  • File downloads block private and local addresses, send no cookies, and have size and time limits.
  • All text from pages and Telegram is shown with safe DOM methods. No innerHTML is used.
  • Background messages are accepted only from the extension's own pages.
  • Strict content security policy for extension pages: script-src 'self'; object-src 'self'; base-uri 'none'.
  • Saved page copies have scripts removed.
  • Bot token and Group ID are checked against strict patterns before every request.

15. Limits#

Item Limit
Uploaded file size 50 MB (2 GB with a local Bot API server and the helper)
Text message 4096 characters (the extension keeps to about 4000)
Caption on a file, photo or screenshot 1024 characters (the extension keeps to 1000)
Selected text 3000 characters
Note 300 characters
Save all tabs 200 tabs per click
Telegram rate limits If Telegram says "too many requests", the extension waits and retries once
File download time 120 seconds
Screenshots Visible area only, not the whole page
Page copy Needs the page to allow script injection. Browser pages and protected sites cannot be copied

16. Troubleshooting#

Problem What to do
Find my group says no group found Make sure the bot is in the group and is an admin. Send a new message in the group, then try again. If the bot has a webhook set, enter the Group ID manually
"Invalid bot token" Copy the token again from @BotFather. Make sure there are no spaces. It must look like 123456789:AAH...
"Group not found" Check the Group ID, including the minus sign. Make sure the bot is still a member
"The bot needs admin rights" Make the bot an admin with the Manage Topics permission
"Topics are off in this group" Open the group → Edit → turn on Topics
"That topic no longer exists" You deleted the topic in Telegram. In Settings → Topics, clear its ID and press Create missing topics in Telegram
Saves go to General The category has no topic ID. Press Create missing topics in Telegram or enter the ID by hand
File button is greyed out Turn on Advanced access in Settings → Features
File was sent as a link The address is a normal web page, not a downloadable file, or the file is over 50 MB
"Downloads from local or private addresses are blocked" This is a safety feature. Download the file yourself and send it from Telegram
"This page can't be copied" Browser pages (for example about: or chrome:) and some protected sites cannot be read
"Cannot reach the helper" Start server.py. Check the address in Settings → Helper
"Wrong helper secret" Copy the secret printed by server.py into Settings → Helper again
Helper download fails The bot posts the reason in the topic. Common causes: yt-dlp is out of date (pip install -U yt-dlp), ffmpeg is missing, or the file is over the size limit
Shortcut does nothing Another extension may use the same keys. Change the shortcut in the browser's shortcut page
Firefox extension disappeared Temporary add-ons are removed when Firefox closes. Load it again, or sign it for permanent use
I changed the Firefox version and lost my settings The add-on ID changed in the rename. Enter the token and group again once

17. For developers#

Layout#

text
src/
  ext.js          Browser API shim, validation, URL helpers, topic detection
  dom.js          Small DOM builder, icons, relative time
  store.js        Storage, profiles, settings, duplicate lookup
  tg.js           Telegram API client and all save modes
  background.js   Context menu, shortcut, message handling, badges
  popup.html/.js/.css      The popup
  options.html/.js/.css    The settings window
  ui.css          Shared design tokens and components
  icons/          16, 32, 48, 128 px
manifests/
  chrome.json     Manifest V3 (service worker)
  firefox.json    Manifest V2 (background page)
  background.html Firefox background page
helper/
  server.py       Download helper
  README.md

Browser differences#

Chrome / Edge / Brave Firefox
Manifest V3 V2
Background Service worker Background page (background.html)
Toolbar button action browser_action
Page copy scripting.executeScript tabs.executeScript
Optional all-sites access optional_host_permissions optional_permissions

All code is shared. ext.js picks browser or chrome automatically.

Data model (storage.local)#

text
profiles:  [{ id, name, token, chatId, cats: [{key,name,icon}], threads: {catKey: topicId} }]
activeId:  string
rules:     [{ host, catKey }]
settings:  { dupWarn, keepHistory, historyMax, helperEnabled, helperUrl, helperSecret }
history:   [{ id, ts, profileId, url, title, catKey, mode, note }]

Add a save mode#

  1. Add the mode to the send() function in tg.js.
  2. Add a button in modes() in popup.js.
  3. If it can be duplicated, add it to the lists in findDup() (store.js) and in send().
